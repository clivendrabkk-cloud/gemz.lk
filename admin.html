📱 Mobile responsiveness & speed

Storefront checks

✓ Responsive viewport

All storefront pages include a mobile viewport declaration.

<meta name="viewport" content="width=device-width,initial-scale=1">
✓ Mobile navigation and safe area

Fixed bottom navigation respects the device safe area.

✓ Touch-friendly controls and inputs

Mobile controls have 44px or larger targets; form text uses a 16px base size to avoid iOS zoom.

✓ Responsive product grid

Catalog grid uses two columns on phones, three on tablets and four on wide screens.

○ Slide-up inquiry cart

The cart opens as a responsive page; a drawer is not enabled.

✓ Lazy product images and video

Product images load as they approach the viewport; homepage videos load near view.

✓ GPU-friendly motion and font preconnect

Motion uses transform and opacity; Google Fonts use preconnect hints.

⚠ Image compression

Use WebP or compressed images to reduce transfer size.

⚠ Server compression and CDN

Configure Brotli or gzip and a CDN in the hosting provider.

📊 Tools & analytics

Connect measurement tools

Google Analytics and Tag Manager

Create a web stream in Analytics and paste its Measurement ID, or create a Tag Manager container and enter its container ID. Avoid configuring the same tag in both places.

Search Console

Add the production URL as a property, select HTML tag verification, then paste only the verification content value above. Submit the generated sitemap after uploading it.

AdSense

Verify and approve the site in AdSense first. Add the publisher ID and ads.txt seller lines; create ad units separately before expecting ads to appear.

Facebook Conversions API

The private token is stored for administrators. Sending purchase events requires a server endpoint and a checkout event source; neither is connected to this enquiry-only storefront.

🗺️ Sitemap.xml

Generate a sitemap file

Builds a downloadable XML snapshot from the current published catalog and pages. This static site cannot publish a database-backed sitemap automatically; upload the downloaded file to the site root after catalog updates.
